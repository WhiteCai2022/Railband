# 轨途测速简明使用说明

适用版本：v0.7.3。更新日期：2026 年 11 月 1 日。

这款工具可以测量手机到服务器的上行、下行网速，同时记录位置、场景和手机提供的 5G／4G 信号信息。测完后，可在网页查看轨迹、下载数据。

**操作顺序：设置参数 → 一键测速 → 途中标记场景 → 停止并保存 → 上传并查看。**

## 1 首次准备

1. 安装提供的 `rail-bandwidth-v0.7.3-tunnel.apk`。已安装旧版时，直接覆盖安装，不用先卸载。
2. 打开手机的系统定位开关。APP 请求权限时，选择“使用期间允许”和“精确位置”，并允许通知。
3. 如果要测移动数据，关闭 Wi-Fi 和 VPN，确认 APP 显示“当前网络：移动数据”。测 Wi-Fi 时则连接所需 Wi-Fi。

## 2 先做一次 60 秒试测

打开 APP，向下找到“测量设置”，按下表填写：

| 设置 | 首次试测填写内容 |
| --- | --- |
| 服务器地址 | `62.234.140.204`，前面不要加 `http://` |
| 端口 | `5201` |
| 行程模式 | 勾选“行程模式：断网自动重连，位置和信号持续记录” |
| 测量方向 | “同时测上下行 ↕” |
| 速率上限 | “5 Mbps” |
| 测量时长 | “60 秒” |
| 采样间隔 | “1 秒” |
| 地理位置 | 勾选“测量时记录地理位置” |
| 路线／行程备注 | 填写便于辨认的名称，例如“城铁试测，靠窗座位” |

回到上方，点击 **“一键测速”**。观察曲线、上下行数字和进度条；到达设定时长后会结束并保存，也可以提前点“停止并保存”。

行程模式的计时包含等待连接和断网的时间。

“5 Mbps”适合先检查功能是否正常；双向时是上下行各限 5 Mbps。要观察网络能跑多快，可选择“不限速”，同时留意流量消耗。**有限速时测到接近上限，不代表网络最大带宽只有这么大。**

## 3 高铁或城铁途中怎么测

1. 保持“行程模式”和“测量时记录地理位置”勾选。
2. 将时长改成“持续测量，直到停止”，填写本次路线备注，再点击“一键测速”。
3. 到达不同场景时，点“城区”“山区”“隧道”“车站”等按钮，或使用“自定义场景标签”。标记后不用重新开始测速。
4. 结束行程时，点击 **“停止并保存”**，等界面完成收尾。

中途断网时不用反复点开始：行程模式会等待恢复并自动重试，位置和信号仍按可用情况记录。网络恢复后还需要重新连接并等待采样，数字不会一定立刻出现。

持续零速时，行程模式也会检查是否真的还有数据进展。常用设置下约 15 秒无字节进展会自动重建测速连接，保留同一行程，并继续采集环境数据；较长统计间隔或很低限速会适当延长检测时间。实际网络仍不可用时，重连也可能继续失败。

持续测量仍受 Android 后台运行限制。长途使用时保持电量，避免清理 APP 后台，并定时检查采集状态；应用被系统结束后，不保证自动接着原行程采集。

## 4 页面上的数字怎么看

| 显示内容 | 简单理解 |
| --- | --- |
| 上行 | 手机往服务器发送数据的速度。 |
| 下行 | 手机从服务器接收数据的速度。 |
| 最近一次 | 最近一个采样区间测得的速度。 |
| 平均 | 已测得区间的平均速度，不把没有结果的断网时段补成 0。 |
| Mbps | 网速单位，数值越大表示这次测得的传输速度越快；8 Mbps 约等于 1 MB/s。 |
| “—”或无新速率 | 暂时没有可显示的新结果，不等于已经测得 0。 |
| SINR／RSRP／PCI | 手机提供的蜂窝信号质量、信号强度和小区标识。空白时不影响继续测速。 |
| 沿用最近位置 | 暂未收到新定位，显示的是之前的位置；留意位置时间。 |

## 5 把数据传到服务器

首次在“服务器数据同步”中填写：

| 项目 | 填写内容 |
| --- | --- |
| 上传地址 | `https://62.234.140.204/api/upload` |
| 上传密钥 | 填写单独提供的“APP 上传密钥”，不要填网页登录密码。 |

点击 **“保存设置并上传待同步记录”**。网络可用时会尽快开始同步；测量结束或重新打开 APP 也会重新请求上传。断网时先保存在手机。

默认不勾选“测速期间同步数据块”，以减少上传对测速的影响。想边测边传时可勾选该项，再点保存；同步会占用网络，可能影响测速结果。

停止后保持联网，查看“待同步”数量和状态。APP 会区分“测速中暂停上传”“正在上传”和“等待服务器确认”；网络中断或系统限制时仍需等待。长行程会连续补传多个数据块；在网页看到该行程“已完整接收”，表示这次行程的数据块已传齐。

## 6 在网页查看轨迹和下载

1. 打开 [行程数据网页](https://62.234.140.204/journeys)，输入单独提供的“网页管理密码”。普通模式记录可从“普通测量记录”进入。
2. 找到对应路线，点击 **“查看详情与轨迹”**。
3. 查看时长、平均速度等信息；地图上绿色点是起点，红色点是终点。点选轨迹或拖动“逐点查看”，可查看对应的位置、时间和网速。
4. 点击“下载完整数据”保存 JSONL 文件；需要清理服务器记录时，点击“删除”并确认。

没有有效定位就无法画轨迹，缺失的路线也不会补画。“已完整接收”只表示上传完整，不代表沿途没有断网。

## 7 导出和删除手机日志

先停止测量，再到“日志管理”：

- **“导出最后一次日志”**：只保存最近一次测试；选择手机中的保存位置后确认。
- **“导出全部日志（含位置、信号 JSONL）”**：保存手机内所有测试。
- **“删除日志”**：可选择删除最后一次或全部本地记录。

需要留存的数据请先导出或确认上传完成。手机删除和网页删除是分开的；卸载 APP 会清除手机里的本地记录。

## 8 常见问题

| 问题 | 先检查这些 |
| --- | --- |
| 一直连不上 | 手机是否联网；服务器地址是否为 `62.234.140.204`、端口是否为 `5201`；是否开着 VPN。 |
| 没有位置或轨迹 | 系统定位是否开启；是否允许精确位置；是否勾选记录地理位置。可到室外或窗边等待定位。 |
| SINR／RSRP／PCI 空白 | 系统定位和精确位置权限是否开启。手机或基带可能没有提供部分指标，空白不等于信号数值为 0。 |
| 网页没有这次记录 | 上传地址和密钥是否已保存；是否还有待同步或需处理项目；保持联网后再查看。 |
| 网页显示等待补传 | 数据块尚未收齐。保持手机联网，测完后可点“保存设置并上传待同步记录”重新请求同步，再刷新网页。 |
| 网速总在 5 Mbps 左右 | 检查“速率上限”是否设为 5 Mbps；需要观察更高速度时调整上限。 |
