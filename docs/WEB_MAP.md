# 网页测量详情与轨迹地图

2026-10-14 已部署到 `https://62.234.140.204/`。本次仅更新网页，手机无需安装新 APK。

## 使用

登录原管理网页，在普通测量或行程列表点击记录标题或“查看详情与轨迹”。

- 概况显示测量时长、上下行平均与峰值、有效定位点数。
- 测量信息显示起止时间（北京时间）、设备、方向、限速、采样间隔、记录数量、场景标签、网络类型和接收完整性。
- 地图按真实定位时间绘制轨迹，绿色为起点，红色为终点。可缩放、拖动；“查看全程”恢复全轨迹视图。
- 点选轨迹、端点或拖动“逐点查看”，显示定位时间、坐标、精度、定位年龄、场景、网络、关联的上下行速率。
- 下载和确认删除继续使用原流程。下载文件保留完整原始序列。

## 数据处理

普通测量 `/measurements/<id>`；行程 `/journeys/<id>`。对应 `/data` 接口与页面均要求管理登录。对下载存档只做只读投影，不修改数据库或原始文件。

上下行均速分别以实际测得的总字节 / 有效区间总时间计算，断网不补零。速率记录数包含双向两行，同时显示去重后的采样区间数。

定位采用原始 WGS84 坐标；按原始定位的单调时间或 UTC 时间排序。旧测量的独立 locations、带位置关联的 samples、新行程 telemetry.raw 内的定位均可识别。重复引用旧位置不会变成一个新 GPS 点；同一坐标的新定位仍保留。

缺少数据块、实际定位间隔超过 120 秒，或位置变化明显超过 600 km/h 加定位精度容差时分段，避免伪造中间路线。每个位置点的速率是与该定位关联的观测值；久未刷新的位置可能关联较晚收到的观测，界面保留定位年龄供判断。

长行程地图最多显示 5000 点，优先保留分段端点和场景变化；极端大量分段或标签时保留真实首尾，并提示只显示部分端点。下载序列不抽稀。无有效定位时明确说明，不生成默认轨迹。

地图组件 Leaflet 1.9.4 保存在服务器本地；底图来自 OpenStreetMap，按用户当前视图请求，不预取或批量下载。底图不可用时仍显示轨迹。底图服务会收到地图区域的瓦片请求，完整测量序列不发送给底图服务。保留版权标注，并在地图页面发送仅包含站点来源的 Referer。[Leaflet 文档](https://leafletjs.com/reference.html)、[OSM 瓦片规则](https://operations.osmfoundation.org/policies/tiles/)。
